# OptiCore 웹사이트 구조 (IA)

> 2026-11 포지션 변경: 주식회사 옵티코어는 **생활·교육·렌탈 분야의 서비스를 안내하고 업체와 고객을 이어 주는 마케팅 회사**다.
> 예전 IT 포지션(SI·ERP·AX·SaaS)의 페이지(/lenses, /method, /principles, /diagnose)는 모두 삭제했다.

## 핵심 아이디어

- 옵티코어는 **안내까지만** 한다. 상담·계약·서비스 제공·결제·환불은 각 제휴 업체가 직접 한다.
- 이용 순서: **비교 → 제휴 업체 안내 페이지 → 업체에 직접 상담 신청**.
- 운영 원칙: 상담 비용 없음 / 옵티코어는 개인정보를 받지 않음 / 실제 서비스는 제휴 업체가 제공 / 제휴 수수료를 받을 수 있음을 밝힘 / 운영사 서면 확인 뒤에만 공개.
- 광고 채널(당근·카카오·네이버·메타·토스) 심사를 통과할 수 있도록 (R-007):
  - 모든 페이지가 혼자서 완성된 페이지, 고유 title·description, https 절대 canonical/og:url
  - 사업자 정보 푸터 전 페이지, 이용약관·개인정보 처리방침 링크, 깨진 링크 0, 360px에서 가로 스크롤 없음
  - **사실만**: 2026-11-20 기준 광고 집행 실적 0건, 운영사 서면 허락 0건, 공개된 제휴 안내 0건. 실적·공식 파트너·검증된·믿을 만한·고객 수·만족도·순위·보장·근거 없는 숫자 금지
  - 광고주 표시: `/company`에 "이 사이트와 광고의 광고주는 주식회사 옵티코어입니다."
  - 사업 영역 한 줄(`/company`, 홈 끝): 온라인 서비스 안내·마케팅(통신판매업 신고), 소프트웨어 개발·공급, 경영·정보기술 컨설팅. IT 세부 내용은 계속 금지

## 사이트맵

```
/                         홈: 회사 소개, 분야(생활·교육·렌탈), 이용 방법, 운영 원칙, 제휴 안내 목록, 문의(이메일), 주요 사업 한 줄
├─ /partners              제휴 서비스 안내 목록 (src/data/partners.ts의 공개 항목만)
│   │                     공개 항목이 없으면: "현재 공개된 제휴 안내가 없습니다. 제휴 업체 확인이 끝나면 이곳에 안내합니다." + 이용 방식 설명
│   └─ /partners/[slug]   제휴 안내 랜딩 (R-005 템플릿) — draft: false 항목만 페이지를 만든다
│                         - 상단: "서비스 제공: ○○" + 제휴 안내 문구(신청 정보 미수집, 수수료 가능성)
│                         - 어떤 분께 맞는지 / 진행 방식 / 신청 전 확인할 점 / 자주 묻는 질문 3~5개
│                         - 상담 신청 버튼: 운영사 URL, 같은 탭, 자동 이동 없음
│                         - ?ch= (daangn·kakao·naver·toss·meta만) → 버튼 주소에 channelParam으로 전달
│                         - draft: true 항목: 빌드에서 완전히 제외 (페이지 없음 → 404, 목록·sitemap·llms 어디에도 이름 없음)
├─ /company               회사 정보(상호·대표·사업자등록번호·통신판매업 신고번호·소재지·이메일), 주요 사업 한 줄, 광고주 문장, 하려는 일/운영 원칙
├─ /terms                 이용약관 (안내만 함, 계약·결제·환불은 제휴 업체와 이용자 사이, 수수료 가능, 안내용 정보, 문의 이메일, 시행일 2026-11-20) — 법률 검토 필요
├─ /privacy               개인정보 처리방침 (수집하지 않음, 제휴 업체가 직접 수집, 호스팅 접속 기록, 이메일 문의, 책임자, 시행일 2026-11-20) — 법률 검토 필요
├─ /404                   찾을 수 없는 페이지 (noindex)
└─ 기계용
    ├─ /llms.txt, /llms-full.txt   공개 페이지 요약 (초안 제외)
    ├─ /sitemap.xml                공개 페이지만 (/, /partners, 공개 제휴 안내, /company, /terms, /privacy)
    └─ /robots.txt
```

## 공통 푸터 (모든 페이지)

상호 · 대표 · 사업자등록번호(+ 공정위 사업자정보 확인 링크) · 통신판매업 신고번호 · 소재지 · 이메일 · 이용약관 · 개인정보 처리방침 · 저작권.
값은 `web/src/data/business.ts` 한 곳에서 읽는다. 연락처는 이메일 하나뿐(전화·메신저·폼 금지).

## 새 제휴 안내 페이지를 여는 순서

1. `web/src/data/partners.ts`에 항목 추가 (`draft: true`, `approvalNote`에 승인 대기 사유). 이 상태에서는 빌드에 전혀 나오지 않는다
2. 운영사에 초안 내용을 (로컬 미리 보기나 문서로) 보내고 **서면 확인**을 받는다
3. `provider`, `operatorUrl`을 실제 값으로 바꾸고 `draft: false` → 테스트·빌드·링크 검사 통과 후 배포
