# OptiCore 웹사이트 구조 (IA)

> 2026-11 포지션 변경: 주식회사 옵티코어는 **생활·교육·렌탈 분야의 믿을 만한 업체와 고객을 이어 드리는 마케팅 회사**다.
> 예전 IT 포지션(SI·ERP·AX·SaaS)의 페이지(/lenses, /method, /principles, /diagnose)는 모두 삭제했다.

## 핵심 아이디어

- 옵티코어는 **안내까지만** 한다. 상담·계약·서비스 제공은 각 제휴 업체가 직접 한다.
- 이용 순서: **비교 → 제휴 업체 안내 페이지 → 업체에 직접 상담 신청**.
- 운영 원칙: 상담 비용 없음 / 옵티코어는 개인정보를 받지 않음 / 실제 서비스는 제휴 업체가 제공 / 제휴 수수료를 받을 수 있음을 밝힘.
- 광고(카카오·네이버 등) 랜딩 심사를 통과할 수 있도록: 모든 페이지가 혼자서 완성된 페이지, 사업자 정보 푸터 전 페이지, 깨진 링크 0, 360px에서 가로 스크롤 없음.

## 사이트맵

```
/                         홈: 회사 소개, 분야(생활·교육·렌탈), 이용 방법, 운영 원칙, 제휴 안내 목록, 문의(이메일)
├─ /partners              제휴 서비스 안내 목록 (src/data/partners.ts). 초안 항목은 '준비 중'으로만 표시, 링크 없음
│   └─ /partners/[slug]   제휴 안내 랜딩 (R-005 템플릿)
│                         - 상단: "서비스 제공: ○○" + 제휴 안내 문구(신청 정보 미수집, 수수료 가능성)
│                         - 어떤 분께 맞는지 / 진행 방식 / 신청 전 확인할 점 / 자주 묻는 질문 3~5개
│                         - 상담 신청 버튼: 운영사 URL, 같은 탭, 자동 이동 없음
│                         - ?ch= (daangn·kakao·naver·toss·meta만) → 버튼 주소에 channelParam으로 전달
│                         - draft 항목: noindex, '초안 · <approvalNote>' 표시, sitemap·llms 제외
├─ /company               회사 정보(상호·대표·사업자등록번호·통신판매업 신고번호·소재지·이메일), 하는 일/하지 않는 일
├─ /privacy               개인정보 처리방침 (수집하지 않음, 제휴 업체가 직접 수집, 호스팅 접속 기록, 이메일 문의, 책임자) — 법률 검토 필요
├─ /404                   찾을 수 없는 페이지 (noindex)
└─ 기계용
    ├─ /llms.txt, /llms-full.txt   공개 페이지 요약 (초안 제외)
    ├─ /sitemap.xml                공개 페이지만
    └─ /robots.txt
```

## 공통 푸터 (모든 페이지)

상호 · 대표 · 사업자등록번호(+ 공정위 사업자정보 확인 링크) · 통신판매업 신고번호 · 소재지 · 이메일 · 개인정보 처리방침 · 저작권.
값은 `web/src/data/business.ts` 한 곳에서 읽는다.

## 새 제휴 안내 페이지를 여는 순서

1. `web/src/data/partners.ts`에 항목 추가 (`draft: true`, `approvalNote`에 승인 대기 사유)
2. 운영사에 초안 페이지 주소를 보내고 **서면 확인**을 받는다
3. `provider`, `operatorUrl`을 실제 값으로 바꾸고 `draft: false` → 테스트·빌드·링크 검사 통과 후 배포
